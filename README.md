# Proyecto Práctico: Innovación y Emprendimiento en Inteligencia Artificial

Repositorio oficial para el proyecto académico enfocado en el desarrollo de una solución de inteligencia artificial basada en datos, aplicando conceptos de innovación, modelos de negocio, ética y escalabilidad.

## 📋 Descripción del Proyecto
Este proyecto simula y resuelve un caso práctico de análisis predictivo (enfoque de clasificación mediante Machine Learning), integrando los fundamentos teóricos de la innovación tecnológica, la validación de un Producto Mínimo Viable (MVP) y estrategias de crecimiento para startups (como modelos SaaS y B2B).

## 🚀 Fases del Proyecto
1. **Definición del Problema y Datos**: Planteamiento de un desafío de optimización y simulación de un conjunto de datos estructurado.
2. **Exploración y Preparación**: Limpieza, normalización (`StandardScaler`) y división de los datos en entrenamiento y prueba (`train_test_split`).
3. **Implementación del Modelo**: Uso de algoritmos de aprendizaje automático supervisado (`RandomForestClassifier`).
4. **Entrenamiento y Evaluación**: Validación mediante métricas de rendimiento como Exactitud (*Accuracy*), Precisión, *Recall* y Puntaje F1.
5. **Conclusiones y Escalabilidad**: Propuestas de crecimiento, arquitectura en la nube y consideraciones éticas frente al sesgo algorítmico.

## 🛠️ Tecnologías y Librerías Utilizadas
* **Python** (Lenguaje de programación principal)
* **Pandas** (Manipulación y estructuración de datos)
* **NumPy** (Operaciones numéricas y simulación)
* **Scikit-learn** (Modelado predictivo y preprocesamiento)

## 📊 Resultados del Modelo
El modelo entrenado alcanzó una **exactitud (Accuracy) de 1.0** en el conjunto de prueba de la simulación actual, demostrando la consistencia y correcta implementación de la tubería de datos (*data pipeline*).
